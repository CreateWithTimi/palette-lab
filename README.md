# palette-lab
An aesthetic WCAG-aware color palette generator built with vanilla HTML, CSS, and JavaScript.

Features
5-color harmony palette generation
WCAG-aware text contrast
Copy HEX interactions
Dynamic DOM rendering
Responsive modern UI
Color harmony principles
Tech Stack
HTML5
CSS3
Vanilla JavaScript
Design Goal

Wanted to turn a basic frontend class exercise into a polished design tool that showcases both frontend logic and design thinking.
